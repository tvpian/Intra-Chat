Intra-Chat is a lightweight intra-network chat application designed for seamless communication within local networks. It is perfect for team collaboration and real-time messaging, offering a simple and efficient interface built with **HTML** and powered by a **Python** backend.

## Features

- **Real-time Messaging**: Communicate instantly within your local network.
- **Lightweight and Fast**: Designed for quick deployment and efficient operation.
- **Team Collaboration**: Perfect for small teams needing a local communication tool.
- **Cross-platform**: Accessible from any device with a web browser.

## Getting Started

Follow these simple steps to get Intra-Chat running on your local network.

### Prerequisites

- Python 3.7 or later installed
- A web browser (e.g., Chrome, Firefox, Edge)

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/tvpian/Intra-Chat.git
   cd Intra-Chat

2. **Install Dependencies**:
    ```bash
    pip install -r requirements.txt

3. **Run the Application**:
    ```bash
    python app.py

4. **Access the Application**:
    Open your browser and navigate to `http://<your-local-ip>:<port>`.  
    Replace `<your-local-ip>` and `<port>` with the details displayed in the terminal when you run the application.


### Configuration

You can configure the application settings (e.g., port, message storage) in the `config.py` file.
