API keys let a teammate's VS Code Copilot agent (or the teammate's own browser) authenticate to the Brain Dump and Inventory APIs without the shared login. Each key is bound to one project and is the only proof of ownership for that project's private knowledge base — anyone holding the key can read, write, and manage that project's entries. Keys are shown once at creation; only a hash is stored on the server.
